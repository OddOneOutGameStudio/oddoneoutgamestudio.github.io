The pitch

Classic tower defense loop: place towers along the path, upgrade or sell them, hold the base against waves of rats. Enemy variants (tank, fast, diva), tower variants with their own projectiles (poison, slow), an economy of build / sell / upgrade, win and lose states, a tutorial and music that changes with the state of the game.

Two goals were written on the wall before the first commit: learn 3D in Unity (assets, camera, Unity 6 behaviour graphs) and build the code around patterns instead of around panic. Both held.

Systems

What we built

106 scripts · 36 PRs
Creational

Factory · Prototype · Pool

Tower and enemy factories, prototypes for variants, an object pool so a wave of fifty rats does not allocate fifty times.

Structural

Flyweight · MVP

Shared tower and enemy data in flyweight registries; the whole UI split into ten presenters and thirteen views.

Behavioural

State · Strategy · Command

Enemy state machines (move, attack, death), targeting strategies (closest, weakest), and build / sell / upgrade as undoable commands wired to the New Input System.

Audio

Recorded by us

ScriptableObject audio library, a dynamic music controller that switches tracks per game state, and fifteen sound effects we recorded ourselves over two evenings.

3D

Models, terrain, particles

Towers, rats, terrain and decorations modelled and animated in-house. First time any of us lit a 3D scene.

Flow

Tutorial & waves

Step-based tutorial with highlights and conditions, wave configs, time-scale control and additive scenes for menu, game and UI.

What we learned

  1. Patterns are cheap when you choose them before writing code and expensive when you retrofit them. We chose first.
  2. MVP for UI meant the designer and the programmer could work on the same panel the same day.
  3. Recording your own sound effects takes one evening and makes the game feel ten times more yours.
